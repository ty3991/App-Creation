Automated suite: `node --test test/*.test.mjs`. Tests cover all three family meshes, independent STL bounds/hole checks, invalid/prototype-key proposals, cost arithmetic, unknown-preserving CAD prompt, API outages and malformed responses, private storage, persistence, idempotency, immutable originals, revisions and approval. Re-run before deployment.

Remaining user/environment checks: owner login creation, API funding and a successful real-model/photo session, physical-phone interaction, print/fit/tolerance/material assessment, cloud TLS/storage/backup/restore/abuse controls and deployment approval. Bambu Studio import verifies scale and loading; it does not establish strength or manufacturability.
